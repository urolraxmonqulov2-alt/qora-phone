QORA SHAHZODA - Android (APK) loyihasi

1) github.com da YANGI PRIVATE repo oching (masalan qora-phone).
2) Shu papka ichidagi hamma narsani (android/ va .github/ papkalari) repoga yuklang
   ("Add file > Upload files"; .github papkasi yashirin bo'lsa ham ichiga kirib yuklang).
3) Repoda Actions bo'limi > "Build APK" > Run workflow (yoki yuklashning o'zi ishga tushiradi).
4) 5-10 daqiqadan so'ng ish tugagach, pastdagi Artifacts dan "qora-shahzoda-apk" ni yuklab oling,
   zipdan app-debug.apk ni chiqarib telefonga o'rnating.
5) Ilovada: Sozlamalar > Groq kalitini kiriting, 1-5 tugmalar bilan ruxsatlarni bering,
   "Tinglashni yoqish" ni bosing. "Qora shahzoda, ..." deb buyruq bering.
Xato chiqsa Actions logidagi qizil xatoni menga yuboring.
